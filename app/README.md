# BessonClient移动端APP  📱
## 帮助文档
### 采用了Kotiln + RecyclerView + Retrokit的自由开源的安卓app, 后端技术栈为springboot + RESTful写法 (详情见studentmanager-for-springboot)

> 任何安卓软件开发者都能加入开发并提交代码，项目使用MIT开源协议
### 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| Kotlin | 主要开发语言 |
| Retrofit 2 | 网络请求 |
| Gson | JSON 解析 |
| RecyclerView | 列表展示 |
| Material Design | UI 组件 |
| ViewBinding | 视图绑定（可选） |
